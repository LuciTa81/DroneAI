# Round 1 공유용 기술 보고서 가독성 개선 설계

## 목적

기존 A4 세로 9페이지 공유본의 기술적 내용과 근거를 유지하면서 화면과
인쇄물에서 쉽게 읽을 수 있도록 글자, 표, 그림을 확대한다. 작은 글꼴을
단순 확대하지 않고 밀도가 높은 장을 분리해 A4 세로 12페이지 보고서로
재편한다.

## 확인된 문제

- 기존 표 본문과 그림 캡션은 6.3~6.5pt여서 일반 화면 배율에서 읽기 어렵다.
- 일반 본문도 8.5pt 중심이라 공유용 보고서로는 작다.
- 여섯 모델 구조표와 일곱 출력 패널을 9페이지 안에 넣으면서 정보가
  지나치게 압축됐다.
- Density와 Point/Hybrid 패널을 반쪽 폭으로 배치해 원본 패널 내부의
  입력·정답·예측·zone 표기까지 작아졌다.

## 산출물

- 형식: 한국어 PDF, A4 세로, 정확히 12페이지
- 성격: 외부 공유 전 사용자 검토본
- 파일명: `output/pdf/DroneAI_Round1_CCTV_모델비교_공유용_확대검수본.pdf`
- 기존 9페이지 PDF는 비교용으로 보존한다.
- 새 PDF와 렌더링 중간 파일은 Git에 추가하지 않는다.

## 가독성 최소 기준

- 본문: 10.5pt 이상, 행간 15pt 이상
- 번호형 핵심 문장: 10.5pt 이상
- 표 본문: 8.5pt 이상
- 표 머리글: 8.5pt 이상
- 그림 캡션: 8.5pt 이상, 행간 11pt 이상
- 헤더·바닥글: 8pt 이상
- 장 제목: 22pt 이상
- 표와 그림에서 말줄임표로 핵심 내용을 생략하지 않는다.
- 실제 출력 패널은 원칙적으로 콘텐츠 폭 전체를 사용한다.

## 페이지 구성

1. **표지**: 제목, 검증 범위, 작성일, 핵심 결론.
2. **요약 및 핵심 결론**: 다섯 가지 주요 판단과 세 가지 해석 주의.
3. **검증 목적·데이터·조건**: 데이터, split, 실행 환경, 학습 여부,
   공통 및 출력 계열별 metric.
4. **모델 구조와 입출력 I**: STEERER, DM-Count, PET를 큰 행과 8.5pt 이상
   글꼴로 비교.
5. **모델 구조와 입출력 II**: MPCount, APGCC, CSRNet을 같은 형식으로 비교.
6. **성능 비교와 해석**: 여섯 모델 수치표와 핵심 결과 해설.
7. **Density 출력 I**: DM-Count와 STEERER 패널을 각자 가로 전체 폭으로
   배치하고 결과를 설명.
8. **Density 출력 II**: MPCount와 CSRNet 패널을 각자 가로 전체 폭으로
   배치하고 결과를 설명.
9. **Point/Hybrid 출력 I**: STEERER와 PET 패널을 각자 가로 전체 폭으로
   배치하고 density·point 차이를 설명.
10. **Point/Hybrid 출력 II**: APGCC 패널을 크게 배치하고 localization과
    zone 활용을 설명.
11. **상용화 권리 및 CCTV 적용 판단**: component-level 권리표, ROI,
    perspective, zone calibration, overlap ownership 원칙.
12. **최종 추천과 다음 단계**: STEERER·DM-Count 우선 검증, PET 연구
    비교군, 현장 검증과 최종 1개 모델 fine-tuning 순서.

## 데이터와 주장 경계

- 기존 비교 JSON, 한국어 모델 설명, SHA-256 검증 패널만 재사용한다.
- UCF-QNRF validation 36장과 canonical split SHA-256을 고정한다.
- 공식 pretrained checkpoint의 cross-domain compatibility smoke 결과이며
  공식 모델 순위가 아님을 표시한다.
- technical score는 정확도 백분율로 표현하지 않는다.
- `PASS_COMMERCIAL_CANDIDATE`를 생산 또는 배포 승인으로 표현하지 않는다.
- PET는 연구 비교군으로 명시한다.
- 재추론, training, fine-tuning, test split 접근, queue 변경을 하지 않는다.

## 구현 경계

- 기존 `round1_share_report.py`의 검증과 입력 계약은 유지한다.
- 페이지 수와 레이아웃만 가독성 기준에 맞게 재편한다.
- 글꼴 크기와 패널 폭을 반환하는 테스트 가능한 layout contract를 추가한다.
- 출력은 새로운 파일명으로 원자적으로 생성한다.
- 12페이지를 Poppler PNG로 렌더링하고 모든 페이지를 시각 검수한다.

## 검증 기준

- pypdf 기준 정확히 12개의 A4 세로 페이지여야 한다.
- 최소 글꼴 계약은 본문 10.5pt, 표 8.5pt, 캡션 8.5pt이다.
- 모든 모델명, 데이터·split, metric, 권리 경계, 최종 추천 문구가
  추출되어야 한다.
- 패널 manifest의 SHA-256 불일치가 0건이어야 한다.
- 그림 내부 입력·정답·예측·zone 영역이 일반 화면에서 구분돼야 한다.
- 한글 깨짐, 표 잘림, 텍스트 겹침, 빈 페이지, 과도한 공백, 작은 캡션,
  헤더·바닥글 누락이 하나라도 있으면 전달하지 않는다.

## 병합 순서

1. 12페이지 확대 검수본을 생성한다.
2. 사용자에게 로컬 PDF를 전달해 가독성 확인을 받는다.
3. 사용자가 승인하면 feature branch를 `main`에 로컬 병합한다.
4. 병합된 `main`에서 전체 테스트를 다시 실행한 후 원격에 반영한다.
